## 🎨 Design Philosophy
- **Aesthetic:** Classy, modern dark theme (deep slate & charcoal surfaces, subtle glassmorphism, soft ambient gradient glows, and refined typography).
- **Typography:** `Plus Jakarta Sans` for elegant headings, `Inter` for crisp body copy.
- **Audio Feedback:** Pure client-side Web Audio API synthesizer for subtle, non-intrusive sound effects (toggleable via the top navigation bar).
- **Responsive:** Optimized for smartphones, tablets, laptops, and ultra-wide desktop monitors.
