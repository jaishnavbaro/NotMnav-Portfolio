## ⚡ Special Interactive & Audio Features
- **Web Audio API Synthesizer:** Built-in sound engine producing crisp 8-bit jump blips, coin score chimes, explosion buzzers, and mechanical clicks (no external MP3/audio files needed). Toggleable on/off via the top HUD `SFX` button.
- **System CLI Terminal (Easter Egg):** Press the `~` (tilde) key or click the `CLI` button in the navigation bar to launch an interactive terminal.
  - Commands: `help`, `whoami`, `skills`, `games`, `specs`, `arcade`, `sfx`, `contact`, `clear`.
- **Custom Gaming Crosshair Cursor:** Smooth cursor with targeting reticle and hover reaction.
- **Ambient Particle Grid:** Dynamic floating particles and laser mesh on background canvas.
- **Live HUD Telemetry:** Active FPS counter, real-time status indicator (`ONLINE`), and Assam, IN region tag.
